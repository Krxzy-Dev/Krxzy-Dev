## About me

I'm Krxzy. I write code most days, mostly backend work plus the front end that sits on top of it.
I like small tools that fix something annoying, and I care more about a thing working properly than about it looking clever.

- Working on: personal projects and a few side tools
- Learning: Rust, properly this time
- Ask me about: APIs, databases, and getting slow code to run faster
- Off GitHub: I read a lot of other people's source code
